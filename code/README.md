# Programs cited by paper A2 as "computed"

Single-file Rust (std only), exact integer or rational arithmetic (`i128`, `i64`), no floating point in any decision. Build: `bash code/build.sh` (`rustc -O`; nothing is run). Computed statements are labelled "computed" in the status table of the paper; none of them is used by a Lean-verified or hand-proved statement.

**Status of this directory.** The 9 programs were compiled once at packaging time (0 failures; nothing was run). The command lines are partly recorded in the `run*.sh` scripts; there is no single reproduction script, and the claim that every number of the paper is regenerated by one command is **not** made. The identification of program and paper statement is by the packager, from the program headers and the paper's status table; it was not checked by rerunning. The scripts call `tools/launch_lite.sh` through `LAUNCH_LITE`; some of them name binaries (`ins2`) built in the author's tree from a variant whose source is not shipped.
